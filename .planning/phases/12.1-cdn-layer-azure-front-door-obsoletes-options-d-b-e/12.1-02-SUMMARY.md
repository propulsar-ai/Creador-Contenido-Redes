## Code delta

### REHOST-06 (`n8n/subworkflow-rehost-images.json`, node `collect-blobs`)

**Before:**
```javascript
const items = $('🔧 Build blob URL').all();
const postId = items[0]?.json?.post_id || null;

const blobUrls = items
  .map(it => ({
    index: it.json.slide_index,
    url: it.json.blob_url,
  }))
  .filter(b => b.url)
  .sort((a, b) => a.index - b.index);

return [{ json: { blob_urls: blobUrls, post_id: postId } }];
```

**After (Phase 12.1):**
```javascript
const cdnHost = $env.AZURE_CDN_HOST;
const rawBlobHost = $env.AZURE_STORAGE_ACCOUNT + '.blob.core.windows.net';

const items = $('🔧 Build blob URL').all();
const postId = items[0]?.json?.post_id || null;

const blobUrls = items
  .map(it => ({
    index: it.json.slide_index,
    url: cdnHost
      ? it.json.blob_url.replace(rawBlobHost, cdnHost)
      : it.json.blob_url,
  }))
  .filter(b => b.url)
  .sort((a, b) => a.index - b.index);

return [{ json: { blob_urls: blobUrls, post_id: postId } }];
```

## Rollback procedures (captured for operations reference)

**Scenario 1 — Meta returns 9004 on real exec in Plan 12.1-03 Task 1 (AFD URL unreachable from Meta fetcher despite 12.1-01 dry-run):**

4. Estimated recovery: ~10 min

**Scenario 2 — AFD itself breaks mid-exec (timeout, 503, regional outage):**
1. `git revert 9120db7` — REHOST-06 back to raw Blob hostname
2. `git revert 3dcf574` — Re-install Options D/B/E in main workflow
3. Re-PUT both workflows
4. Estimated recovery: ~15 min

**Anti-pattern warning:** Unsetting `AZURE_CDN_HOST` env var alone does NOT roll back — it only affects the hostname emitted by REHOST-06 but does NOT restore Option D/B code in the main workflow (those are pure code, not env-driven). Unsetting the var results in "Meta calls with raw Blob URL = 9004 every exec" — worse than Options D/B/E.
