### Edit 8/14: Agregar nodo `🛡️ Assert FB Story URL (no SAS)` (id `assert-fb-story-url`) — FBSTORY-04 cerrado en Phase 12

**Goal:** Defense-in-depth Code v2 node que strippa cualquier query string (`?...`) de la Azure Blob URL antes de pasarla al FB Upload. Razón (FBSTORY-04 del REQUIREMENTS): el Meta STORIES fetcher de Facebook es más estricto que el FEED fetcher y puede rechazar URLs con SAS query params (sig=, sv=, sp=, se=, st=, sr=, spr=). Las Azure Blob URLs actuales que produce `🔁 Re-host Images` en Phase 11 son bare permalinks (sin SAS query), pero esta assertion blinda contra futuras rotaciones de SAS sin perder la sesión de aprobación.

**Decisión de implementación (Option A — strip, NO reject):** Si la URL viene con `?...`, eliminamos todo desde `?` y devolvemos el bare URL. Es no-destructive (no aborta la exec por una URL técnicamente válida que igual funciona en bare form), y el comportamiento es predecible en la traza n8n. Si en E2E aparece evidencia de que Meta acepta el SAS suffix sin issue, este node se vuelve no-op pero queda como guardrail para Phase 13 sin agregar latencia mensurable (<1ms Code v2).

Position `[5280, 480]` (entre `🔀 ¿Plataformas FB?` y `📤 FB: Upload Story Photo Unpublished`).

```json
{

    "mode": "runOnceForEachItem",
    "jsCode": "// FBSTORY-04: Strip Azure SAS query params from blob URL before FB Story Upload.\n// Meta STORIES fetcher (graph.facebook.com/{PAGE_ID}/photos para Story) es más estricto que el FEED fetcher\n// y puede rechazar URLs con query string SAS (sig=, sv=, sp=, etc.). No puedo passear una URL inválida al FB Upload.');\n}\nconst qIdx = rawUrl.indexOf('?');\nconst sasParams = ['sig=','sv=','sp=','se=','st=','sr=','spr='];\nlet bareUrl = rawUrl;\nlet stripped = false;\nif (qIdx > 0) {\n  const qs = rawUrl.slice(qIdx + 1);\n  const hasSas = sasParams.some(p => qs.includes(p));\n  if (hasSas) {\n    bareUrl = rawUrl.slice(0, qIdx);\n    stripped = true;\n  }\n}\nitem.fb_story_image_url = bareUrl;\nitem.fb_story_url_stripped = stripped;\nreturn { json: item };"
```
